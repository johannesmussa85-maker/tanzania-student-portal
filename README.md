# Tanzania Student Portal

A student resource portal published with GitHub Pages.

**Live site:** https://johannesmussa85-maker.github.io/tanzania-student-portal/

## Main sections

- Home and study resource discovery
- College and university study resources, course materials and official higher-education guidance
- Digital Library search powered by the Open Library catalogue
- Course-family guides and official TCU / NACTVET directory links
- University and college application guidance
- Student CV builder and career links
- Application-letter and field-report drafts
- CSV spreadsheet starter and presentation-outline export
- Browser-local study checklist and theme/language controls

## Important accuracy and privacy notes

- Third-party resources are linked for learning; the portal does not claim to own those resources.
- Verify examination details with NECTA and institution/programme approval with the relevant official regulator.
- Course pages are broad study-field guides, not a complete official list of all Tanzanian programmes.
- The current account page is informational. This static GitHub Pages site does not provide secure account creation, server-side authentication, or cloud-saved profiles.
- Dashboard checklist data is stored in the current browser/device when browser storage is available.
- Document tools create Word-compatible `.doc`, `.csv`, and plain-text slide outlines; they do not currently generate native `.docx`, `.xlsx`, or `.pptx` files.
- Review generated drafts and replace all guidance placeholders with accurate personal details and verified observations before submitting.
- Do not enter passwords, sensitive personal data, or private documents into features that do not explicitly need them.

## Updating the site

The site is a static HTML/CSS/JavaScript project. GitHub Pages publishes the contents of the configured branch/folder. After edits, allow publishing time and check the live page on both desktop and mobile.
