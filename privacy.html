Privacy

Your privacy matters

This page explains the main data-handling practices of this static GitHub Pages website and the precautions students should take while using external services.

Static website

The portal is published as a static website on GitHub Pages. It does not currently provide its own secure server-side account system, cloud profile storage or password database.

Browser storage

Some features, such as the student dashboard checklist and display preferences, may store information locally in your current browser/device. This is not the same as a cloud account.

External services

Some pages connect to external websites or public services, such as educational institutions, Open Library, OpenStax, MIT OpenCourseWare and other resource providers. Those services have their own privacy policies and terms.

External links

When you leave this portal and open another website, that site's data practices apply. Check the destination domain and its privacy information before submitting personal data.

Information you should not enter

Do not enter passwords, payment-card details, government identification numbers, private academic records or other sensitive information into features that do not explicitly require and securely process them. The current account page is informational and does not provide live authentication.

Changes to this page

Privacy practices may change as the portal gains new features or integrations. This page can be updated to reflect those changes, and the latest version will be published here.

Need to report a privacy concern? Use the Contact page and avoid posting sensitive personal information publicly.
